# PES6 自建服务器（Windows 私服联机）

PES6（实况10）Windows 自建私服联机系统——在自己电脑开服务器，和朋友联机对战。内置 UDP 中继，客机零配置（无需公网 IP/端口映射/UPnP）。

## 快速开始

- **只想玩**：见release 网盘包说明
- **想自建**：完整文档在 [`pes6server/README.md`](./pes6server/README.md)（主机 4 步 / 客机 3 步）

## 本仓库包含

- `pes6server/` —— 一键启动/关闭脚本、Fiveserver 配置、自建 STUN 中继（已打包 exe）、Kitserver 6.8.0、完整部署文档
- 不含游戏本体与 MySQL 运行库（体积/版权原因，获取方式见文档）
